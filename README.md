# Decoding Customer Value: A SQL-Driven Retention Strategy

## Overview
This project analyzes customer behavior for a direct-to-consumer (D2C) fashion brand using Python, SQL, and Power BI.

The goal is to identify:
- High-value loyal customers
- Promotion-dependent customers
- Customer satisfaction patterns
- Retention opportunities
- Product/category trends

The project combines:
- Data cleaning & feature engineering (Python)
- Customer segmentation & business queries (SQL)
- Interactive executive dashboard (Power BI)
- Retention strategy recommendations

---

## Business Problem
The brand has strong customer behavioral data but lacks a structured retention strategy.

Key concerns include:
- Over-reliance on promotions and discounts
- Difficulty identifying genuinely loyal customers
- Lack of visibility into customer value drivers
- No segmentation framework for retention decisions

---

## Objectives
- Measure promotional dependency
- Build customer value segments
- Identify loyalty patterns
- Analyze satisfaction signals
- Recommend retention-focused business actions
